# WWZT-711 · 飞书 AI 字段关联账号时报错，API Key、模型名和接入点 ID 应该怎么核对？

## 直接答复

先看字段当前要求填写的是凭证、模型标识还是推理接入点，不要把它们互换；同时确认所选模型真的支持这次输入。

## 适用条件

正在配置飞书AI字段与外部模型账号，关联或调用报错，能查看字段说明、模型后台和脱敏报错。

## 操作步骤

1. 记录报错类型和字段提供方，查看该字段当前关联说明，明确需要哪些参数。
2. 在对应服务后台确认凭证可用及权限范围，将 API Key 只填在授权位置，模型名或接入点 ID 填在指定位置。
3. 检查模型能力：图片理解要支持图像，视频分析要支持视频；文本模型不能因名称相似就替代。
4. 检查账号余额、调用额度、接入点状态和区域等实际要求；不要只凭聊天会员判断接口可用。
5. 先关闭自动更新，仅保存配置，用一条可读取的正常素材试跑；确认字段引用和结果正确后再扩大生成范围。
6. 需要协助排错时提供脱敏报错和参数类型，不把完整凭证发到聊天、截图或共享表格正文。

## 如何检查

最小样例成功，参数类型和提供方一致，结果确实来自当前行素材；凭证未作为普通数据暴露给协作者。

## 限制

不同字段和模型版本可能支持直接模型 ID 或独立接入点，不能照旧教程固定要求某种方式。关联成功不代表套餐或模型能力都符合任务。
