# WWZT-519 · AI 报告写在聊天里，团队用不到，怎样让 Agent 真正完成共享交付？

## 直接答复

把读取资料、实际创建或更新、回读检查作为同一项任务，交付到团队正在用的位置。

## 适用条件

宿主可调用飞书 CLI 等已授权工具，需要把分析结果交给团队继续使用。

## 操作步骤

1. 先说明可读材料、要解决的问题、最终文档或表格位置及验收内容；使用已有上下文，不要求用户重写背景包。
2. 核对连接器是否已安装、登录并具有目标权限；飞书操作通过飞书 CLI 执行，能力不足就说明具体缺口。
3. 让 Agent 读取原资料、分析并实际写入目标，保留必要原始定位、版本与下一步动作。
4. 写完回读核对标题、正文、表格或媒体是否完整，返回可访问的交付链接。
5. 下一次协作先读这份最新产物再继续，避免靠一段无限增长的聊天传递全部上下文。

## 如何检查

从团队账号实际能打开成果，内容与报告一致；“我已完成”的聊天文字不能代替文件或云端对象。

## 限制

工具能建文档不代表能配置全部内置AI字段或自动化；涉及外发、权限和发布时按实际授权范围执行。
