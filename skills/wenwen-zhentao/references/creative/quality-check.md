# 创作提示词交付质检

生成、修改、复刻或裂变后读取。检查文本可执行性、事实和一致性，不是实际成片认证或销售效果预测。

## 硬门槛

任一适用项失败就先修正，不能用总分抵消：

1. 商品事实与必保创意未被擅改；未知参数、认证、功效、结构不充作事实。
2. 产品内容有用途/主卖点、可信动作和可见结果；证据不足时是演示，不是虚假测试。
3. 动作、台词和镜头能放进时长，时间连续不重叠，不把秒点当帧级保证。
4. 拍摄关系、人数、固定/手持、单镜头/剪辑兼容，没有假第一人称或重复身体。
5. 每份素材主体、采用和排除明确；多视角商品图绑定同一实体与数量。
6. 阶段有起态、一个主要变化和可见终态，商品、人物、道具、空间与声音不无因跳变。
7. 接触、受力、工具、材料和前后态合理，不依赖危险测试或虚假即时功效。
8. 素材确实读过；忠实复刻的事实与可靠原话未暗改，改编未冒充原片内容。
9. 字幕和音频分开，“不要字幕”未删原声；嘴型/画外音、同步动作声、连续环境声明确。
10. 编辑母版与范围清晰，延长/关键帧能承接；不虚构模型语法或逐像素不变能力。
11. 只诊断未被变成重写；要求生成/修好时已给完整成品，不仅给方法或补丁。
12. 裂变数量准确，每条实质不同且独立可复制，无事实漂移、“同上”或意外占位符。

关键素材不可读时如实指出未确认部分，完成能确定的部分，不用“自检通过”隐藏缺口。

## 按任务选重点

| 任务 | 重点 |
|---|---|
| 新写商品词 | 事实/创意/未知；一个主卖点；动作证明什么，结果怎么看见 |
| 最小修改 | 商品、人物、场景、必保结构和有效约束保留，每处改动有原因 |
| 忠实复刻 | 主事件、机位、人数、相对节奏、平台市场、台词和音轨对应素材 |
| 跨市场/换商品 | 明确改编范围，迁移结构而不臆造商品事实，语言现场合理 |
| 生成重试 | 实际对比过，观察与归因分开，只强化有关约束 |
| 10 条裂变 | 数量、实质变量、统一事实、独立可执行与横向差异 |

快速商品广告可查前 3 秒是否理解产品与痛点/好处，各短段是否有效。忠实复刻有意悬念、安静或慢开场，不因通用广告偏好就强改原片。

## 常见矛盾的最小修法

| 冲突 | 修法 |
|---|---|
| 固定机位又手持跟拍 | 按目的保留一种 |
| 一镜到底却跳地点或成品 | 连续展示过程，或明确剪辑及前后态 |
| 佩戴不变又举起展示 | 改为触碰仍佩戴的物品或调整镜头 |
| 多角度图变多件商品 | 一个实体，逐图分工，固定数量 |
| 视频动作与文字流程相反 | 保留指定继承范围，删除冲突动作 |
| 只写“真实自然” | 改为距离、光线、行为、接触与声音 |
| 加强露出导致混合视角 | 先恢复谁拍谁，再用真实同框接触展示产品 |
| 不要字幕变成无声张嘴 | 恢复对应口播和同步声音，画面单独禁字幕 |
| 反复失败只加禁用词 | 检查素材职责、构图、复杂度，改主约束或缩小任务 |
| 10 条只换近义词/人名 | 重选未锁定的实际任务、动机、动作或场景变量 |

## 可选内部评分

复杂任务可沿用上游量表辅助自查：商品事实 15、证据链 20、结果可见性 10、素材职责 10、人物场景 10、阶段连续性 10、镜头可执行性 10、时长信息密度 5、声音口播 5、限制能力边界 5。

不适用项排除，按适用项得分/满分归一为 100；不足 80 继续修改。这是 AI 对文本的内部审阅，不冒充人工评分、生成实验或业务验收，普通交付不必展示。

素材缺口不能靠捏造事实凑分。一条漂亮结果也不证明某个词有因果作用，更不能声称保证爆款。

## 出口检查

只拿到该代码块，能否知道商品、素材职责、事件、拍摄、声音与结束状态？不能就补齐该条，别让用户在几段解释间拼接。

最终保留必要说明和完整产物。对未知、未读、未生成、未实测如实说明，不额外输出长评分表或通用风险清单。
