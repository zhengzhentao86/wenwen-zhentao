# WWZT-702 · 每个参考文件都能上传，组合在一起却不能生成，先检查什么？

## 直接答复

单个文件合格还不够，要分别核对本次请求的文件数量、各类素材合计时长或大小，以及当前模式允许的素材组合。

## 适用条件

同一批图片、视频或音频单独上传正常，组合提交时失败，能够查看当前入口和完整报错。

## 操作步骤

1. 保存完整报错，确认实际模型、模式与入口，区分网页和接口是否采用同一限制。
2. 先核对每个文件的格式、尺寸、帧率、时长和大小；不把画幅比例、分辨率和文件容量混为一项。
3. 再数图片、视频与音频数量，分别累计视频和音频时长，并核对整次请求限制。
4. 检查素材组合，例如该模式是否接受仅音频，是否需要至少一张图或一段视频。
5. 只留关键素材做最小请求，逐个加回；精简与本镜头无关参考，避免为凑信息重复上传。

## 如何检查

最小请求能提交后，每次加入的素材及其是否触发限制可解释；最终参数与当前入口实际要求一致。

## 限制

不同版本、模式和 API 的额度不互通。扩大上传上限也不表示更多主体或更长参考一定更稳定。
