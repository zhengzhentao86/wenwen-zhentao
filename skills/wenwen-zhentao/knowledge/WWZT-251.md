# WWZT-251 · AI 字段结果出现星号和井号，是乱码吗？

## 直接答复

先判断是否是 Markdown 标记；可以让 AI 输出纯文本，也可以用支持 Markdown 的预览方式阅读。

## 适用条件

文字内容完整，但周围出现 #、** 或列表标记。

## 操作步骤

1. 看一小段原文能否正常读懂。标题前的井号、重点两侧的星号通常只是格式。
2. 只需复制文案时，在输出要求里写“纯文本，不用 Markdown 标记”；保留内容而非逐字手删。
3. 需要排版报告时，使用宿主已有 Markdown 预览能力；插件是否存在及权限按当前市场说明核对。

## 如何检查

分别检查可读性和内容完整性；若是字符替换成问号、内容缺失，转为编码或截断排查。

## 限制

不能把所有显示异常都当Markdown；内容缺失或字符替换应另查编码和截断。
