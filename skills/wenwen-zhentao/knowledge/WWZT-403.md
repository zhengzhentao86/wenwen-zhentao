# WWZT-403 · 会员、积分或 API 收费变了，怎样核对自己的实际权益和扣费？

## 问题

会员、积分或 API 收费变了，怎样核对自己的实际权益和扣费？

## 答复

以当前账号的套餐、订单和任务预估为准，把会员权益、模型计费与 API 消耗分别核对。

1. 先固定平台、账号套餐、模型、任务类型、时长、分辨率，以及是否带参考视频；这些条件不同不能直接比较。
2. 查看生成前的当前费用预估、套餐权益、续费说明与剩余额度；老套餐是否保留权益要以本账号实际合约为准。
3. 用相同小任务试做，记录实际扣费、重跑次数、等待时间与可用成片数，再比较单位可用成片成本。
4. 第三方入口还需核实模型标识、服务方收费、使用权限和素材处理方式；不能仅因声称“满血版”就判断质量更好。
5. 新旧套餐、取消续费和折扣恢复等问题，保存对应页面或订单信息向服务方核实，不据群内旧报价购买账号。

## 适用条件

需要估算预算、续费、选择生成入口或解释积分变化。

## 限制

以当前账号、入口和任务规格为准，不假定图片免费、老会员权益永久不变，或所有VIP与API模式画质相同。

## 检查方法

列出同条件小样本的实扣费用与合格结果数，费用除以合格结果数；没有合格结果时单独记录失败成本，不能算成低成本成片。
