# WWZT-510 · 同一段提示词在创作 Agent 和直接视频生成里效果不同，怎么选入口？

## 直接答复

只有粗略想法时可让创作 Agent 帮忙策划；提示词与分镜已经明确时，优先选可直接提交和设置参数的生成入口。

## 适用条件

工具同时提供对话式创作和直接视频生成，结果被改写或参数不一致。

## 操作步骤

1. 查看最终提交内容，确认 Agent 是否扩写、删改了商品约束、动作或声音要求。
2. 已有完整提示词时，在直接生成入口核对模型、参考绑定、时长和画幅；不要只在聊天里提一遍参数。
3. 确实需要 Agent 帮忙时，让它先完成策划，并检查实际用于生成的版本与原需求是否一致。
4. 比较两个入口时保持模型、素材与参数相同；入口本身支持哪些设置以当前界面为准。

## 如何检查

可以找到实际提交的提示词及参数，而不只是聊天中最初发送的那段。

## 限制

直接生成也有随机性；不能把某次结果变化全归因于 Agent，两个入口可能调用不同模型或默认设置。
