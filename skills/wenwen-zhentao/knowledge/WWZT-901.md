# 歌曲已经有了，怎么把它做成 MV，又不把几十个镜头弄乱？

一句歌词对应一条镜头记录，先定人物与风格，再小批出图、选图、生视频，最后对齐歌曲节奏。时间不够可以先用真实照片完成。

1. 先选交付规模：照片加歌词字幕可以直接成片；完整 AI MV 再加入图生视频，不必一开始做几十个动态镜头。
2. 把歌词按句分开，一句一行，保存画面描述、人物/道具参考、选中的图、视频提示词、最终视频和完成状态。由助手随制作同步，不要求你额外补一份台账。
3. 先统一人物、场景和画风；每次只处理3—5句，选好对应画面再推进，避免整首歌一次生成而漏句、串镜头。
4. 图生视频时写本镜头发生的动作及镜头变化，已经完成的镜头及时标记，把最终素材按歌词顺序命名。
5. 剪辑时先导入音乐，通过文稿匹配或字幕对齐歌词位置，再放对应画面；需要调时长时以节奏和动作自然为准。

检查：随机选一句歌词，能立即找到相应图片和最终视频；从头播放，确认画面、歌词和歌曲节奏一致。
