# Blender 做好的白模动画，怎么接到即梦继续生成？

在 Blender 启用对应白模上传插件，从相机渲染或选择本地白模视频，再把它送到即梦作为参考视频。插件负责导出和衔接，最终生成仍在即梦完成。

1. 从即梦官网的插件入口下载与你系统匹配的 Blender ZIP 包。
2. 在 Blender 的 Edit → Preferences → Add-ons 中选择 Install from Disk，选中ZIP安装，保持插件勾选启用。
3. 回到3D视图，按 N 打开右侧 Sidebar，找到 Jimeng 面板。
4. 尚未导出时选“相机渲染”，确认相机、分辨率、帧范围和保存位置，再渲染；已有白模视频时选“本地上传”，选择文件。
5. 点击“上传至即梦生成”，进入网页后确认正确的白模视频已经出现在参考素材中，再补充你要的视觉风格、人物或商品参考。

找不到面板先查插件是否启用、当前是否在3D视图；跳转后没有素材，则检查本地视频是否成功导出、文件能否播放及当前上传限制。看到跳转页面不等于视频已被正确载入。

这里的菜单名称对应已收录插件教程；使用前核对当前插件版本、宿主版本和官方说明，入口变化时按当前说明定位。
