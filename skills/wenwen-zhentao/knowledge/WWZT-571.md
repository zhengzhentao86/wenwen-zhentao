# 已经上传主播声音，生成视频却没用上，怎样把配音固定住？

先区分要借用音色说新台词，还是要原封不动使用一条成品配音。需要稳定保留声音时，先把配音做对，再让人物按这条音轨说话。

如果你希望它借用主播的音色重新说一段话，检查当前模型和入口是否支持音色参考，并确认提示词确实引用了已上传的音频。音频已经上传，不代表模型一定会按它生成。

可以先用一句短台词检查。如果多次仍然换声，改为两步：先录好目标台词，或用获授权的声音在支持克隆的工具里生成配音；听过确认后，将这条完成的音轨交给支持音频驱动的数字人工具或视频流程。人物形象再单独使用清晰、获授权的参考图或角色素材。

需要保留原音轨时，可这样描述：

```text
使用已上传的【配音音频】作为本段完整声音，不重写台词、不重新配音，不改变音色、语速、停顿和声音时长。
人物使用【角色参考图】，按配音做口型和自然动作。视频长度与音频一致。画面保持【场景要求】，不增加背景解说。
如果当前工具不能直接沿用音轨，请明确指出，不要用另一种声音代替。
```

先听声音是否还是原来的那条，再看口型、动作和停顿是否同步。若视频工具只能生成新声音，就在剪辑时使用已确认的原音轨，配合支持口型同步的流程；不要把“音色听着像”当成完整音轨已经原样沿用。
