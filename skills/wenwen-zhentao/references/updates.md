# 使用时更新

新开始使用本 Skill 时读取并执行一次；连续答疑期间不重复检查。用户明确要求检查版本时可再检查。

## 先分清能力

基础答疑依赖读取随包知识。联网、Python 3、安装目录写权限和宿主重新加载是独立能力；不要凭“支持 Skill”就推定全部具备。

发行信息在包内 `version.json`。更新源尚未配置时正常用现版，不自行编造 URL 或改用候选知识。只有维护者已经发布的正式源才用于自动更新。

## 支持脚本的宿主

使用实际 Skill 安装目录和安装目录之外的用户应用状态目录。状态目录由当前宿主和操作系统决定，不硬编码维护者路径，不放在会被升级替换的包内。

以下参数中的路径必须换成当前环境的真实路径并正确引用：

```sh
python3 -B "实际安装目录/scripts/update.py" --skill-dir "实际安装目录" --state-dir "用户应用状态目录下的问问镇涛目录" check --apply
```

此命令检查版本并在发现新版时尝试安装。按照脚本的真实返回结果处理，不凭退出码或下载完成推断成功：

- `not_configured`：没有正式发行源，静默继续当前答疑。
- 无新版：继续现版。
- 确认安装成功：核对返回的安装版本；重新读取当前安装目录的入口与本题所需知识。宿主需要重新加载或新会话时，给明确操作并保留当前问题摘要，不宣称当前会话已经切到新版。
- 离线、下载/完整性/结构验证失败或目录不可写：保留并使用原可用版本。说明影响时简短即可，不反复重试，不擅自提高权限。

更新器只更新本 Skill 与对应知识；不用更新学员其他 Skill，不运行发行包附带的任意安装钩子。用户对话、素材和记录不随版本检查上传，也不存放到会被替换的安装目录。

## 能力不足的宿主

没有脚本、网络或写权限时继续答疑，不把检查失败说成“已是最新版”。若确有已知正式发布入口，可给宿主自身的安装/重新导入方法；没有发布入口就如实说明尚未配置。

宿主只能读取导入的静态知识包时，更新需要重新导入；这是该宿主的限制，不保证靠文字指令可以自动安装。

本地候选包或测试包不等于已经对外发布；只在真实发布源及兼容性验证存在时承诺相应自动更新能力。
