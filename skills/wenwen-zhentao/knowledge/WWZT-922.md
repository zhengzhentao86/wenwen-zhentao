# 爆款案例库从哪里来，怎样积累才不会存了一堆不再看？

把日常找参考变成小量持续的习惯，收集时保留视频和选择理由，再让AI分析、分类和检索。找案例本身也是训练内容判断的过程。

可以设一个专门看行业内容的账号，日常收藏、关注相关优质内容；同时看店铺后台、行业榜单或已有数据工具。团队每人每天少量分享值得学的案例，比一次导入几千条却没人理解更容易持续。

收集时保留原链接、日期、商品/人群、值得借鉴的一点，以及有权限取得的视频文件。已有信息由助手补齐标签，不要求大家重复填表。榜单上的历史表现和眼下看到的素材分开记录，有近期数据再判断是否仍有参考价值。

检索按同品类、相近品类、不同品类但同受众三层找。输出不只给链接，还说明借哪个结构、哪些镜头或商品事实不能照搬，下一条怎样改成自己的产品。

季度或季节变化时回看往年同期素材，同时检查商品、活动和受众是否仍匹配。案例库的验收方式是：给一个当前商品，能找出少数合适参考并解释具体怎么用；收藏数量多本身不算完成。
