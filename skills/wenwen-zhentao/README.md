# 问问镇涛

基于镇涛课程知识的 AI 助教与创作工具箱：课后答疑、商品视频提示词、诊断与修改、参考视频复刻、提示词裂变，以及三视图、故事板和素材处理提示词。

完整入口包包含 `zt` 与 `wenwen-zhentao`：把两个文件夹并排放入 AI 工具支持的 Skill 目录。保留各包内的相对位置。Codex 桌面输入 `/zt`，选中 `zt` 后说需求；CLI 可用 `$zt`，原长入口仍可用。其他宿主的斜杠菜单和安装目录以其真实支持为准。

`zt` 只负责短入口，知识与版本检查仍在本核心包中。单独安装核心包也能使用；要启用短入口，请安装完整入口包。对应专用 Skill 已安装时按需联动，缺项就用内置模块，不需要学员选模块或装额外依赖。

直接问即可，例如：

- “故事板只有两个镜头画错了，要全部重新生成吗？”
- “产品包装上的文字一直不对，有什么办法？”
- “视频只有 5 秒，配音有 12 秒，怎么处理？”
- “多维表格链接转附件后打不开，先检查什么？”
- “给这个随行杯写一条 15 秒视频提示词，卖点是单手开盖。”
- “只诊断这条提示词，先不要重写。”
- “照着这个参考视频的结构，换成我的产品。”
- “保留这条母版的卖点和证明动作，裂变 10 条完整提示词。”
- “按这张人物图写三视图提示词。”
- “把这段视频提示词转成故事板，只修改原来第 2 格。”
- “给我的视频写去水印和高清修复的处理提示词。”

问题明确时直接答；确实需要看提示词、截图或视频时，再请你补充。能否分析媒体、联网核实和自动升级，取决于你使用的 AI 工具。

## 当前公开版

v0.5.1 包含 191 条实操答疑与方法，以及商品提示词、复刻、裂变和素材模板模块。支持局部改视频与续写、音轨、达人拍摄说明、团队落地、素材复盘、竞品与直播话术分析、多维表格和数据口径问题。

文字答疑可直接使用。用户明确要求图片或视频文件时，AI 检查宿主的真实工具与输入：可以执行就处理并核对文件，缺少能力时交付提示词和下一步。写好处理提示词不代表已生成媒体。

最新版与完整安装包：https://github.com/zhengzhentao86/wenwen-zhentao/releases/latest

包内配置公开更新地址。具备 Python 3.9+、网络和安装目录写权限的宿主使用时检查并尝试更新，离线时使用现版；其他宿主重新导入最新包。答疑本身无需登录维护者飞书、填写 API 密钥或部署服务。
