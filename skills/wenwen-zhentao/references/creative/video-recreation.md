# 视频复刻、反推与差异诊断

用户说“拆这个视频”“反推提示词”“复刻爆款”“生成后不像原片”“再修一版”时使用。复刻依据可观察的结构与效果，不能仅凭标题认定原片确有爆款表现。

## 先读到素材，再下结论

先查看参考视频与可用音轨；有生成尝试时同时看生成片、对应提示词和反馈，按相同动作节点或时间点对照。材料够用直接完成，不逐步骤请求确认。

只能访问截图时，可分析可见产品、构图和状态，不能声称听过口播、确认运镜或完整动作。链接不可访问时说明具体缺口，请求文件、关键帧或时间点描述；不把名称、封面和摘要当原片。

音轨、台词或关键过程确实不可读时，先完成确定部分，集中索要必要补充。飞书/Lark 链接按主 Skill 的 `lark-cli` 规则处理，不换浏览器绕过权限。

## 忠实复刻与改编

- **忠实复刻**：保留实际主事件、叙事顺序、拍摄关系、人数、相对节奏、语言和已确认音轨；不擅自换平台、国家或广告风。
- **明确改编**：按目标换商品、市场、平台或创意，保留可迁移的痛点—证明—结果结构；改动与新台词标为改编。
- **默认判断**：“复刻”默认忠实，“换成我的产品/改成另一市场”按相应范围改编。可推断时直接做，不额外要求选菜单。

先确定真正发生的事件。若产品只是任务中的佩戴物或道具，先写生活事件，再按原有比重安排产品；不把修理、通勤或玩笑硬改成孤立产品展示。

平台市场分三层：通用事件与物理逻辑；平台节奏、口播与转化方式；语言、现场与本地道具。跨市场只调整需本地化的层，商品包装、参数和事实不能臆造。地区缺可靠证据时保持中性，不根据脸猜身份或国籍。

## 内部观察表

不必展示长表，但写提示词前至少确定事实与不确定项：

| 维度 | 观察内容 |
|---|---|
| 整体与主事件 | 时长、画幅、连续拍摄/剪辑、发生了什么、结尾结果 |
| 拍摄关系 | 谁拍谁、拍摄者是否出现、第一人称/自拍/同伴拍/固定、人数 |
| 主体与状态 | 商品外观、位置、数量、佩戴/手持/安装状态，人物与道具归属 |
| 动作因果 | 准备、接触、变化、结果的顺序，每步如何导致下一步 |
| 表达目的 | 哪些镜头识别产品、表现痛点、证明、展示结果或建立信任 |
| 成像现场 | 景别、角度、运镜、曝光、光线、压缩裁切及必要职业/生活痕迹 |
| 声音 | 原话、说话人、起点、嘴型/画外音、环境声、动作声、音乐与停顿 |
| 文字 | 字幕、贴纸、包装、界面、水印分别是什么，保留/排除哪些 |

## 画面文字与声音分别处理

“不要字幕”“忽略字幕”只约束画面字幕、贴纸或文字层，**不能自动删除口播、画外音、音乐、环境声和动作声**。仍读原音轨；烧录字幕用于复核听不清的词，不能代替检查声音。

有说话内容时，内部建立：

```text
时间码 → 说话人 → 可靠原话 → 对口型/画外音 → 同步可见动作 → 环境/动作声 → 叙事或卖点作用
```

原声听清而字幕不同，以可辨实际语音为准；不确定处标记。忠实复刻不编原话、不静默省掉口播。用户要求改编时才能设计新台词，并标为改编台词。

参考开场有声时，写明 0.0 秒的首句或动作声；停顿保留低层环境声，不掉成数字静音。剪、撕、刮、敲、按等接触对应同一时刻声音，不只写“有环境音”。原片本来安静或故意延迟声音时保留设计，不机械加声。

拆多段生成时，每段可独立执行，但复用同一声音参考或宿主支持的同一声线标识，明确相同语速、混响、响度和连续音乐的承接位置。各段使用局部时间，逐句台词与动作对齐，不重复问候或重启音乐。模型不支持时保留完整声音稿及后期衔接说明，不冒称已锁定。

## 写成可执行约束

结合 [商品提示词](product-prompts.md) 的事实、素材职责和阶段状态方法，只增加与本片有关的约束：

| 漂移 | 写清什么 |
|---|---|
| 同伴拍变第一人称、单人变多人 | 谁拍谁、拍摄者不入镜、可见人数，不混入拍摄者肢体 |
| 穿戴物变手拿展示 | 始终在佩戴位置，以轻触仍佩戴的物品表现，避免含糊“拿给镜头看” |
| 商品消失在背景任务里 | 证明动作里如何接触、承重、运行或使用；不以抢镜比例压过拍摄关系 |
| 一步跳到完成品 | 准备、操作、接触、结果的顺序与相对时间；后态由前态产生 |
| 工具/材料换种类 | 具体形态、接触位置、受力方向；材料尺度、层数、干湿和平整状态 |
| 贴膜流程失真 | 按原片保留裁剪、揭背层、定位、接触、刮平、修边；不提前成品 |
| 物理效果乱变形 | 效果来源 → 接触路径 → 同步响应部位/衣物 → 稳定结构，不以身材变化替代作用 |
| 反光面多出人脸机位 | 允许反射哪些对象；仅手部参考不无故出现脸、身体或另一人倒影 |
| 手机片变精致广告 | 原片可观察的普通光线、轻微压缩、局促距离、曝光变化与不完美构图 |
| 人物不像真实操作 | 正确工具、目光、接触、受力及必要现场痕迹，不靠“真实”形容词补救 |

只选当前相关约束，不全表复制。原片危险测试或物理错误应指出并给同卖点的安全可信替代，不因忠实而美化误导结果。

快速带货片检查前 3 秒是否识别产品、痛点/好处和证明开端，每个短段承担产品、痛点、证明、结果、信任或收尾作用。忠实复刻若原片有意悬念或慢开场则保留，不按通用广告模板擅自重排。

## 收到生成片后怎么修

1. 对齐参考、实际使用的提示词、生成片与反馈，单独检查开场，再看证明及结果。
2. 先说观察到的差异，再给可能归因；单次随机生成不能证明某句话必然导致问题。
3. 选择最关键的 1–3 处修正，例如恢复机位/人数，固定工具接触，再补同步音频；保留已接近参考的约束。
4. 给完整新版，简述修改和下一次核对标准，不只给补丁或长禁用词清单。
5. 同问题补充一次仍存在，重新检查素材职责、主体构图和动作复杂度；必要时换更明确的单主体参考或拆成可承接片段，不继续堆同义禁用词。
6. 新版变好时记录可能有效的约束及剩余偏差。当前经验不自动变全局规则，更不证明转化提高。

仅明确要求维护 Skill 时，把可复现、可迁移教训形成候选，走主 Skill 审核流程。普通试错不上传原片、客户素材、提示词或日志，不调用上游社区/后台。

## 交付

只要提示词：完整代码块及必要不确定说明。通常复刻：简短镜头意图/改编范围 + 完整词。诊断重试：差异 → 可能原因 → 完整新版 → 核对标准。只问哪里不对时不擅自重写。

有提示词范式则保留其模块名称、顺序和大致密度，修正冲突而不强换长模板。交付前执行 [质检](quality-check.md)。未实际生成、观看或测量，就不能说“已经复刻成功”。
