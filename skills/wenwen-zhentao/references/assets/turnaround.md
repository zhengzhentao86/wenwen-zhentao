# 人物三视图：可复制模板

适用问题：用人物参考图或完整原创角色文字设定，建立后续生图、生视频的人物资产；或修正已有设定图中某个视角。

## 最少需要什么

- 人物参考图或完整的原创角色文字设定，有一种即可。原创设定足够明确时直接起稿，不因没有图片要求用户先找图。
- 要保持已有特定人物的长相或既有造型时，需要该人物的实际参考图；已有图片就直接使用，不重复索要。文字创作出的角色不称为已核验的真人还原。
- 只有要求准确还原现有背部、鞋子或其他不可见细节时，再索取对应角度参考。原创文字已写明的细节按设定绘制；未写明的部位可作一致的创意补全，并说明补全范围。
- 若用户只要提示词，直接给模板；若明确要求生成图片，再检查当前是否有可用的图像生成／编辑工具。

## 可直接复制的中文模板

```text
请根据我提供的人物参考图或完整原创角色文字设定，制作一张人物三视图设定图，作为后续生成图片和视频的一致性参考资产。

【人物依据】
使用本次已提供的参考图或原创角色文字设定，不要求我重复提供已有材料。
只有文字时，若人物外观、服装与画风等已足够明确，就直接按设定设计初版，不强制索取参考图。尚未提供的原创文字设定可粘贴在这里：
【原创角色设定：按需填写；已有完整设定或参考图时不用重复填写】
如果我要求保持某个已有特定人物的长相或既有造型，则以该人物的实际参考图为准；缺少图片时，请求必要参考，不把文字想象当成已核验的身份还原。
如我提供多张图，先核对是否为同一人、同一造型；有冲突且会影响结果时，只询问必要的那一处差异。

【输出与版式】
生成 1 张 16:9 横版图片，纯白背景，清晰、均匀的光线。
左侧约三分之一区域：同一人物的正面面部近景，完整呈现主要五官与发型。
右侧约三分之二区域：从左到右依次排列正面、侧面、背面三个全身视图。
三个全身视图大小接近、脚底基线对齐，头顶和鞋底均完整入画，不能被裁切。
人物自然站立。侧视图使用清楚的正侧面，不用含混的斜侧面替代。

【一致性】
四个区域必须是同一人物、同一年龄感、同一造型和同一画风。
有参考图时，保留其中可见的脸型、五官比例、肤色、发型、发色、发饰、体型、服装颜色、材质、纹理和配饰；不美化成另一个人，不重新设计现有人物。
按原创文字起稿时，遵循已明确的外观、服装与画风，在四个区域保持同一套设计；不擅自改写已有设定，也不增减与参考图或文字设定冲突的衣服和饰品。
正面、侧面、背面的头身比例一致。侧面体现身体厚度与服装层次；背面体现后部发型、服装与鞋子的合理结构。

【不可见部位】
参考图没有展示的背面、鞋子或被遮挡部位，只能依据可见信息作克制的设计补全，不把它描述为已准确还原。
原创文字已规定的背面、鞋子等按设定绘制；未规定的部位作与整体一致的创意补全，不假称有原始图像依据。
若我明确要求这些部位与真人或现有服装完全一致，先指出缺少哪个角度，并请求对应参考图。
交付时说明哪些部位属于推测补全，供我核对。

【画质】
以当前工具实际支持的分辨率生成。工具支持且可设置时，可将 4K 作为目标输出参数；不能仅因提示词写了“4K”就声称文件已达到 4K。
清晰呈现五官、衣物边缘和可见材质，不使用过度磨皮、锐化或虚构纹理制造假细节。

【不要出现】
不要剧情场景、海报排版、动态姿势、额外人物、无关文字或新增水印。不要把三个全身视图误做成三个不同的人。
这是人物参考设定图，优先保证身份一致、布局清楚与完整全身。
```

## 已有三视图，只修一个区域

已提供原图和明确目标时，仅补齐「修改哪个视图」「哪里不对」，不要求用户重新描述整个人物。可在上面的模板后追加：

```text
本次是在我上传的已有三视图设定图上局部修改。
只修改：【面部近景／正面／侧面／背面中的具体区域】。
需要改正：【具体问题及对应参考，例如“侧面鞋型与参考图不一致”】。
其余区域保持原有构图、人物、比例、服装、背景与位置；不要把整张图重新设计一遍。
如果当前工具无法锁定编辑区域，先说明这一限制并给出局部修正方案，不承诺其余像素完全不变。
```

## 输出边界与检查

- **给出模板不等于已经生成图。** 有可用工具且用户已要求生成时，才调用工具并交付实际输出文件；没有生成能力时，明确交付的是可复制提示词。
- 能查看输出时，核对左 1/3 面部近景、右侧正／侧／背顺序、三个完整全身、人物与服装一致性；不能查看时，说明尚未完成视觉检查。
- 实际尺寸须读取文件或工具返回的尺寸；拿不到尺寸时标记未核验，不宣称「已交付 4K」。
- 推测补全的背面、鞋底等仍需用户核对。生成图适合作为一致性参考，不证明模型已重建真实三维结构。
