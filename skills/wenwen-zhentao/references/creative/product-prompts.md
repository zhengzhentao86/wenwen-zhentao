# 商品视频提示词：写、诊断与最小修改

用户说“帮我写商品视频提示词”“这个词哪里有问题”“保持原思路改一下”“换成图生视频”时使用。直接交付提示词或诊断，不要求用户先学习模板。

## 交付什么

| 用户意图 | 本次交付 |
|---|---|
| 从商品、卖点或模糊创意开始 | 一份可直接复制的完整提示词 |
| 润色、修好、改成另一生成方式 | 保留原稿基线，交付最小必要改动后的完整提示词 |
| 只诊断、先别改 | 主要问题 → 具体影响 → 最小修改建议；不擅自重写 |
| 有参考视频，要复刻或对比生成结果 | 先读 [视频复刻](video-recreation.md)，观察实际素材后再写 |
| 裂变 10 条、再来不同版本 | 读 [提示词裂变](prompt-variants.md)，一次交付全部独立版本 |

## 足够就做，不反复问

已有“商品 + 一个卖点”、商品图配说明、商品配创意，或一份待诊断提示词即可开始。使用已有上下文，不重复索取。只有缺项会改变商品事实、核心目标或判断路径时，集中追问最少的必要问题；无法识别商品时不能捏造对象。

用户说“直接做”且事实足够时，采用必要默认值并简短说明：通用短视频、15 秒、9:16、一个生活场景、一个主卖点、一条连续动作链、真实手机拍摄、自然现场声、无字幕、无 BGM。已有稿件、参考视频和明确要求优先于默认值；不能用默认声音策略覆盖参考音轨。

无真实商品图也能写，但不猜颜色、材质、接口、Logo 或内部结构。未知结构优先不展示；非展示不可才索要对应图或说明。真实产品图是外观依据，创意图中的样品不能反过来改写真商品。

把参考视频换成自己的商品且要求外观准确时，使用清晰实物图和关键镜头参考，先核对关键静态画面，再进入视频生成；在交付步骤中保留这道检查。文字改写完成不能替代外观核对，也不能保证一次成片。

## 锁住事实与原稿基线

- **事实**：用户明确提供、实际素材可确认或有可靠依据的商品属性与效果，保持不变。
- **创意**：合理的人物动作、场景、拍摄方式和口语表达，可为完成目标设计。
- **未知**：未提供的参数、材质、认证、功效、品牌事实、背面结构，不补造成事实。

改已有稿前锁定：商品与参考图特征；指定人物、场景、动作、台词及转化目标；平台、市场、语言、时长、画幅；必须保留与禁止项。只补缺项、消除矛盾、改写不可执行动作，不借“优化”换掉整套创意。

内容互相冲突时，说明关键冲突与最小修法，优先最近的明确要求。合理默认能解决的细节直接完成；两种选择会改变主要意图时才追问。

## 先组织证据，再写镜头

按两层关系组织提示词：

1. 商品事实 → 使用痛点 → 一个主卖点 → 可信证明动作 → 可见结果。
2. 生成方式 → 素材职责 → 阶段状态 → 镜头声音 → 连续性与限制。

“结实、舒服、方便”不是镜头。把卖点落到实际接触、操作和结果上；人物夸赞与旁白不能替代证明。证据不足时写使用演示，不设计虚假对照或保证效果。

| 品类 | 可选证明或演示方向 | 不能从演示擅自推出的结论 |
|---|---|---|
| 工具、防护、户外 | 正常任务中的抓握、穿戴、接触、收纳 | 防一切伤害、极限承重、绝对安全 |
| 服装、鞋包 | 行走、转身、活动、装入已知物品 | 未知容量、防水等级、虚构面料性能 |
| 美妆、个护、香氛 | 取用、质地、喷雾、便携使用 | 治疗、永久改变、仅靠路人反应证明功效 |
| 数码、小家电 | 连接、启动、完成一个明确功能 | 未知参数、接口、速度和不存在的 UI |
| 家居、清洁、收纳 | 同一局部的处理、展开收起、取放 | 整屋瞬间变化、剪辑伪装成连续测试 |
| 食品、饮料 | 开封、倒出、搅拌、可见质地与食用 | 未知成分、产地、减重和医疗效果 |
| 健身与身体用品 | 正确姿势下的贴合、稳定、调节与使用 | 身体瞬间变化或未经依据的疗效 |
| 饰品、数字产品 | 细节佩戴；真实任务流程 | 虚构材质等级；生成准确界面代替真实录屏 |

15 秒通常一个主测试及一次结果展示。副任务只服务主卖点：卖护膝时可以测量、够取物件等简单动作展示接触和承重，不另编完整维修教程。

## 分配素材职责

明确写“素材编号 → 对应主体 → 采用属性 → 排除内容 → 使用阶段”，不只写“参考以上素材”。

- 商品图约束形状、比例、颜色、已知结构和标识位置；不默认继承背景、手或道具。
- 同一商品正反侧图共同定义一个实体，明确全片数量，不能变多件或混合零件。
- 人物图只约束对应人物可见外观；多人逐一命名，动作、衣服和声音不交换。
- 场景图采用指定空间关系、光线或材质，不顺带复制其他商品。
- 参考视频继承明确的动作路径、节奏或运镜；已有动作正确时不另写冲突顺序。
- 音频分别绑定说话人、台词、音色、环境声或音乐；实际可读部分才能称为已分析。
- 首尾帧/关键帧分别定义构图与起止状态，写清中间连续动作，不承诺逐帧复刻。

冲突按明确要求与素材指定职责处理，不把不同款式融合成新品。准确包装小字、价格、标识和界面使用真实素材、录屏或后期图层；不把随机生成文字当成准确呈现。

## 让阶段能够接上

普通新创作可用“开场 0–3 秒 → 证明 3–9 秒 → 结果 9–12 秒 → 收尾 12–15 秒”，根据真实动作调整，不能硬套到忠实复刻。

每阶段交代三个要素：

```text
开始或承接状态：商品、人物、道具在哪里，处于什么状态。
主要事件：一个主要动作、交接或变化。
结束状态：镜头直接看见的结果，能成为下一阶段的开始。
```

跨阶段核对商品身份与数量、人物服装、道具归属、开合/干湿/佩戴状态、左右前后、摄影轴线、运动趋势和声音来源。商品从手中到桌面须有放下动作；佩戴物未取下不能变成手持展示。

时间段是事件预算，不是帧级剪辑保证。动作或台词放不下就删减或合理延长，不靠“快速完成”压缩不可能完成的过程。

## 具体到能拍出来

先确定谁拍谁、可见人数、第一/第三人称、固定/手持、单镜头/剪辑、距离与跟随对象，再要求商品显著。不能同时写固定机位和手持跟拍，或一镜到底和跨地点跳转。

把“真实”落到光线、手机距离、轻微曝光变化、生活痕迹和现场声；把“专业”落到正确工具、接触位置、姿势与动作。按场景选择，不把杂乱、汗水、压缩噪点当成所有视频的配方。

声音分为口播、环境声、动作声、产品声和音乐。写清谁说、对谁说、何时说，台词能在对应阶段自然说完。目标市场明确时台词用目标语言，导演说明仍用中文；市场不明不编国家、口音或平台购物指令。

## 按生成方式适配

| 方式 | 重点 |
|---|---|
| 文生视频 | 完整写已确认外观、人物、场景、动作和声音，减少同时复杂运动的主体 |
| 图生视频 | 输入图是外观和起始构图基线；写允许动作和保持项，避开未知结构 |
| 多镜头 | 一致锚点和衔接明确；总时长正确，不再声称一镜到底 |
| 编辑 | 唯一母版；明确对象、区域、时间或声音类别及保持项 |
| 延长 | 从原尾帧继续或到原首帧结束，姿态、位置、光线、动作方向与声音连续 |

模型未指定或能力未核实时，用通用自然语言。不虚构特殊符号、素材/时长上限或参数锁定；指定模型时依据当前官方说明或用户界面适配。无原生音频时保留声音制作稿并说明需后期完成，不删台词。

## 交付

先执行 [质检](quality-check.md)，自行修正。生成/修改任务输出“必要假设（若有）+ 完整可复制代码块”；只要提示词时省略分析。代码块按需包含规格、产品事实与证明、素材映射、人物场景、机位、阶段状态、声音和针对性限制，不留空标题。

诊断只列影响最大的实际问题及最小修法；不能仅凭提示词断言未看过的成片已出故障。用户说“修好”时补完整新版，不只给补丁。文本检查通过不等于视频已生成或实测有效。
