# WWZT-035 · 团队共用课程表格，怎样避免复制后工具都失效？

## 问题

团队共用课程表格，怎样避免复制后工具都失效？

## 答复

团队共创优先围绕同一张工作表配置协作权限，再单独核对外部工具授权。

如果目的是在同一工作流协作，可在现有工作表中给成员配置必要权限，避免每人复制一份后各自维护配置。然后用普通协作者账号测试一条记录，确认字段可执行、结果可见。

表格可编辑与外部 API 可调用是两件事；后者要按组织账号及服务方的实际授权方式配置，不把私人密钥填进可见单元格。

## 适用条件

同一团队需要在一套课程工作表中共同提取、分析和生成内容。

## 限制

组织共用配置不等于任意平台都允许共用个人账号或密钥；实际权限与服务条款应单独核实。
