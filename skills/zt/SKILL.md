# 问问镇涛 · zt

这是问问镇涛的短入口。用户只需说要解决的问题，不需要选择子模块、记住其他 Skill 名称或重新提供已有背景。

1. 先读取与本入口同级安装的 `../wenwen-zhentao/SKILL.md`，再按其中的路由加载对应模块。若该相对位置不存在，从宿主已发现的 Skill 列表定位 `wenwen-zhentao`，读取它的实际入口；不要硬编码维护者电脑路径，也不要搜索无关私人目录。
2. 以用户本次输入和当前对话的有效目标为任务。`/zt`、`$zt` 只是入口标记，不属于提示词内容。仅输入入口且已有待办时继续处理；没有目标时只问一句“你现在想解决什么问题？把问题或素材直接发来就行。”
3. 读取核心包的 `references/routing.md`，自动选择包内模块或已安装的专用 Skill。先复用背景、已读素材和已完成成果，再完成用户要的结果；不要停在列出推荐 Skill。
4. 只有实际读入专用 Skill 或通过宿主成功调用后，才算使用了它。缺少外部 Skill 时使用核心包内对应模块；不要替用户自动安装依赖。

核心包无法找到时，说明“问问镇涛核心知识包尚未安装完整”，给出将发行包内 `zt` 和 `wenwen-zhentao` 两个目录并排放入同一 Skill 目录的修复办法。能够直接解答的部分可标明“AI 补充”继续，不能声称已使用镇涛知识。

更新与知识只有核心包一份，由核心入口检查版本；本入口不复制知识、不独立检查、不回调自身。已在当前任务加载核心入口时，直接继续路由，避免循环加载。
