# Maya 里的即梦白模插件装好了，为什么找不到入口或不能导出？

先确认安装脚本完成，再到 Maya 插件管理器加载上传器；出现上传器面板后，才能选择相机渲染或本地视频。

1. 解压官方插件包。Mac使用 install_maya_plugin.command，Windows使用 install_maya_plugin.bat；确认安装过程完成后重新打开 Maya。
2. 在“窗口 → 设置/首选项 → 插件管理器”进入浏览，找到插件包的 plug-ins 文件夹，打开 jimeng_maya_uploader_plugin.py。
3. 搜索该插件，勾选“已加载”和“自动加载”。确认页面出现即梦白模渲染上传器入口。
4. 选“相机渲染”时，设置相机、分辨率、帧范围与保存位置；选“本地上传”时，选已有白模视频，按面板完成预览/处理。
5. 点击“上传至即梦生成”，在网页核对参考视频内容与时长，再继续生成。

如果还是没有入口，提供Maya版本、操作系统、插件版本和加载报错；不要反复只重装安装包。若Mac安全提示阻止安装，先确认下载来源与文件身份，再按系统对该文件的允许方式处理，不关闭全局安全保护。

这里的菜单名称对应已收录插件教程；使用前核对当前插件版本、宿主版本和官方说明，入口变化时按当前说明定位。
