# 我只有衣服图片，怎样先做一条自然的模特穿搭视频？

先做好模特穿着衣服的静态图，确认款式和场景，再让模特做一个简单动作。静态图已经不对时，先修图再生成视频。

1. 准备同一款服装的清晰商品图，有背部设计、纹理或特殊装饰时补对应细节。以图锁定衣服，不靠一大段文字重述外观。
2. 先生成模特穿搭图，明确人物类型、场景和构图。只有人物要求、没有场景要求，模型可能只给白底；想做居家或街头展示，就把场景写进这一轮。
3. 静图检查衣领、袖型、图案、背部、长度及穿搭关系；确认后再生成动态。上衣可以中近景展示，整套或连衣裙用能看全轮廓的构图。
4. 一条先做一个简单动作，例如自然走近、轻侧身展示版型或调整衣摆，不把转身、跑跳、换装都塞进去。
5. 需要换场景，保留商品与人物约束，只修改场景段；需要多SKU变装，为每款提供参考并明确顺序，先把单款跑通。

静图提示词：
```text
用附件中的这件衣服制作一张自然穿搭照片。衣服款式、颜色、纹理和装饰保持参考一致。模特为【目标人群的外形与气质】，在【场景】中【站姿】，构图【中景/全身】，自然光、日常拍摄感。不要把参考图中无关的背景和其他衣服带进来。
```
动态提示词：
```text
以上传的穿搭图为基础，人物自然地【一个动作】，镜头【固定/轻微跟随】。保持衣服和人物一致，动作幅度自然，重点看清【版型/袖口/下摆】。不要新增配饰，不做突然换装。
```

### 进一步处理


将风格变量与服装不变项分开写：光线、地点、色调和氛围可以调整，版型、颜色、面料与关键设计必须保持。先用轻动作展示，手部不要挡住需要看清的设计。
