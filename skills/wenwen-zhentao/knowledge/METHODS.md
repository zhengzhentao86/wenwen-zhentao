# 按问题选方法

这份导航用于选择处理路径。先匹配当前目标，再打开相关卡片正文；每次只读能改变本次操作的内容，不向学员展示目录或编号。局部报错直接检索答疑，不套完整流程。

| 眼前问题 | 先读什么、何时再深入 |
|---|---|
| 不知道下一条拍什么、卖点翻来覆去 | [从人群与场景找方向](WWZT-916.md)，把[参数翻成买点](WWZT-917.md)；方向多时再[排优先级](WWZT-918.md)，确定后[落成一条可拍任务](WWZT-921.md)。 |
| 有文案，但说服力不足 | 先[准备真实证明素材](WWZT-502.md)；比较[不同说服结构](WWZT-919.md)，按需补[结尾行动引导](WWZT-902.md)。 |
| 想复刻或裂变已有素材 | 先选[直接参考还是反推](WWZT-110.md)，进入包内复刻或裂变模块；脚本改写可选[四种母版改法](WWZT-504.md)，批量前做[单变量小样](WWZT-044.md)。 |
| 视频能生成，商品或动作总不稳定 | 按症状查[多参考分工](WWZT-036.md)、[商品细节](WWZT-015.md)、[尺度](WWZT-012.md)或[动作连续性](WWZT-017.md)，用[单变量排错](WWZT-011.md)比较。只读与偏差有关的卡。 |
| 想选数字人、固定人物或声音 | 选择内容形式读[数字人口播适配](WWZT-570.md)；人物复用读[角色资产](WWZT-111.md)，制作读[口型检查](WWZT-411.md)；声音未采用读[音色与原音轨](WWZT-571.md)，情绪平淡读[表达调整](WWZT-716.md)。 |
| 已有视频，想修局部或继续生成 | 只改一处读[局部编辑](WWZT-700.md)，接着演读[视频延长](WWZT-701.md)；去音乐读[保留人声画面](WWZT-704.md)，清晰度处理读[低清与超分验收](WWZT-508.md)，按任务进素材处理模块。 |
| 服装或系列商品需要批量展示 | [先确认穿搭图再做视频](WWZT-914.md)；多款同人换装读[防串款检查](WWZT-513.md)，图文批量交付读[场景、文案与返修管理](WWZT-913.md)。 |
| AI 有产量，业务效果却不清楚 | [区分生产与经营](WWZT-200.md)；有数据再按[点击与转化排查](WWZT-505.md)，检查[同脚本不同商品的成交前提](WWZT-920.md)。不从画面质量直接推断成交。 |
| 拉片很多，仍不知道下一步 | 用[结构化拉片](WWZT-163.md)和[统一标签](WWZT-171.md)沉淀逐条信息；[表格与Agent分工](WWZT-517.md)做跨条比较，随后[落成制作任务](WWZT-921.md)并[复盘](WWZT-169.md)。 |
| 素材越存越多，团队却找不到 | [积累可用参考案例](WWZT-922.md)；群链接用[视频标识去重](WWZT-518.md)，剪辑调用用[分镜库](WWZT-507.md)，复现生产保留[完整输入与结果](WWZT-165.md)。 |
| 想选品、看类目或比较竞品 | 先核对[样本口径](WWZT-300.md)，再做[卖点回查](WWZT-301.md)或[评论分析](WWZT-305.md)；商品标题任务用[搜索词与标题](WWZT-712.md)。 |
| 想和达人合作，或判断竞品达人策略 | 先[核对主竞品](WWZT-1104.md)与[渠道归因](WWZT-1105.md)，再[筛选达人](WWZT-1106.md)、[写拍摄说明](WWZT-1107.md)，按需[跟进交付](WWZT-1109.md)。 |
| 直播或本人表达需要改善 | [直播话术结构](WWZT-302.md)与[自身对照](WWZT-303.md)用于话术；[灯光与布景分析](WWZT-710.md)用于场景；本人风格用[真实口播样本](WWZT-202.md)。 |
| 多维表格、分析列或自动化卡住 | 先定位[凭据与模型](WWZT-711.md)、[字段类型](WWZT-254.md)或[后续列没触发](WWZT-720.md)；批量前[小样验证](WWZT-255.md)，自动通知检查[触发时机](WWZT-257.md)。多表关联读[跨表引用与同步](WWZT-1110.md)，AI评分临界冲突读[统一评级规则](WWZT-1101.md)。 |
| 报告需要交给团队，或团队接不住 | 交付结果读[实际创建与回读](WWZT-519.md)；组织落地从[小任务试点](WWZT-306.md)开始，用[交接验收](WWZT-204.md)与[流程迭代](WWZT-308.md)接住经验。 |
| 资料很多，学完还是不会做 | [知识库选入口](WWZT-904.md)解决资料调用，[AI私教练习](WWZT-521.md)解决理解与应用，[能力自查](WWZT-522.md)确定下一项训练。 |

用户要提示词、图片或成片时，以可用成品为交付；导航是助手内部选路依据，不要求学员按卡片顺序学习、填表或维护资产。
