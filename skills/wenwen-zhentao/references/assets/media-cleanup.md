# 去水印、去字幕与高清处理

适用于用户拥有或获准处理的素材。不要把「写好处理方案」「工具开始运行」「已交付并核对结果文件」混成同一种完成状态。

## 最少需要什么

| 任务 | 最少信息 | 只在有必要时补充 |
|---|---|---|
| 去水印／去字幕 | 原图或原视频；要移除的具体位置或内容 | 视频中目标出现的时间段、是否移动；能明确定位时不重复索要圈选图 |
| 高清处理 | 原图或原视频；用途或目标输出要求 | 工具需要指定尺寸时，再核对原始尺寸与目标；人脸、文字、商品细节有特殊保真要求时，再问需要保留的部位 |

缺少原文件但用户只想要提示词，可以直接提供模板。用户要实际处理文件时，应先取得可读取的原素材；截图不能替代完整视频进行逐帧处理。

为用户定制处理提示词时，把最终检查写进可复制的提示词正文，不能只给保真禁令或在正文之外提醒：去水印需检查残余字迹、重复纹理、边缘过渡与误擦主体；高清需与原图对照构图、商品结构、文字、颜色和自然纹理，检查过度锐化及伪影。没有实际执行时，这些是给处理工具的验收要求，不冒称已经完成检查。

## 去水印／去字幕：可直接复制

```text
请对本次上传、由我拥有或获准处理的图片／视频进行局部清理。

【要移除的内容】
位置或圈选区域：填写要移除的水印或字幕位置。
如为视频，适用时间段：填写时间范围；若确实覆盖全片可写“全片”。
需要清理的是上述指定叠加内容，不包括商品主体上原有的品牌文字、包装信息或场景中本来存在的标识。

【处理要求】
只处理指定区域，尽量利用周围可见画面与前后帧衔接填补。
优先保持人物、商品、背景、构图、颜色和已有细节，不扩展修改范围，不改变人物身份或商品外形。
如果水印／字幕遮住了真实信息，说明该区域只能估计补全；不要声称已找回被覆盖的原始文字、五官或纹理。
如果遮挡正好覆盖人脸、商品关键细节或大范围运动物体，先指出具体难点，并给出保留原版或小样处理的建议，不承诺无损还原。

【视频额外要求】
跟踪目标的位置变化，避免只清理第一帧或静止位置。
保持原时长、帧顺序、原有帧率与音轨；未经我要求，不改速、不插帧、不新增配音或背景音乐。
检查目标出现和消失的时刻、运动过程与镜头切换处，避免残影、闪烁、涂抹块、背景跳动和误擦主体。

【实际执行与交付】
如果我本次只要提示词，返回可执行的文字方案即可。
如果我已明确要求处理文件，且当前已有工具支持这类编辑，使用现有工具处理并交付实际输出文件；若需区域遮罩或关键设置，只补问缺少的部分。
没有合适工具、无法读取视频或无法取得处理结果时，明确说明当前只完成了方案，不声称水印已移除。
不要为完成此任务启动服务、下载安装外部工具或默认使用付费批量处理。
交付时说明处理范围、观察到的缺陷与尚未核验的部分，保留原始素材供对照。
```

## 高清处理：可直接复制

```text
请对我上传的图片／视频进行高清处理，以改善适合观看和制作的清晰度，同时尽量保持原始内容。

【目标】
用途：填写预览、剪辑、成片交付或其他用途。
目标尺寸／分辨率：填写明确要求；没有硬性要求时，依据原始素材和现有工具能力给出合理建议。
特别需要保真的部位：如人脸、商品包装文字、花纹、边缘；没有则按原图／原视频保留。

【处理顺序】
先判断原始素材是否存在明显压缩噪点、失焦、运动模糊或本来就没有记录到的细节，再选择与问题相符的轻度降噪、修复或放大方式。
先对选中的素材或代表性短片段测试，检查结果后再按我已明确要求的范围处理，不默认批量处理所有素材。
保持原始宽高比、构图、颜色、人物身份、商品比例与重要文字，不裁切关键区域，不重新设计画面。

【细节边界】
不要用过度锐化、磨皮、强行补纹理制造“看起来很清晰”的假细节。
不可辨认的包装文字、脸部细节和被遮挡部分，不能保证从低清素材中准确恢复；需要精确一致时指出应补充的高清参考或原文件。
工具支持时，可以把 4K 设为目标输出参数；“输出尺寸达到 4K”不等于“恢复了真实 4K 细节”。没有实际文件尺寸和可见结果，不声称已完成 4K 修复。

【视频额外要求】
保持原时长、帧顺序、原有帧率与音轨。除非我明确提出，不做插帧、改速或音频替换。
检查相邻帧的人脸、文字、边缘与纹理是否稳定，避免每一帧变得不同、闪烁或拖影。

【实际执行与交付】
如果我只要提示词，提供文字方案，不声称已经生成高清文件。
如果我明确要求处理文件且已有合适工具，就用已可用工具执行；没有相关工具时，说明限制并给出可复制的操作方案。
不要为此启动服务、安装外部工具或默认进入付费批量处理。
交付实际输出文件；能读取文件信息时列出处理前后尺寸，视频同时核对时长、帧率与音轨是否保留。没有取得的指标明确写“未核验”。
说明已检查的画面或时间点以及仍存在的问题，保留原文件用于对照。
```

## 如何判断真的完成

1. **先看文件是否存在且能打开。** 只有提示词、任务编号、进度提示或工具口头回执，都不足以证明用户拿到了处理后的图片／视频。
2. **再核对处理范围。** 去水印检查指定区域及其出现的时间；高清处理对照人物、商品、文字和边缘，避免把生成的新细节当作恢复的真实细节。
3. **最后记录实际检查。** 能读取就核对文件尺寸、视频时长、帧率与音轨；视觉检查标明检查过的画面或时间点。只看了抽样关键帧，就说是抽查，不声称逐帧确认全片无问题。

宿主能看图片但不能处理视频时，可以分析关键帧和给提示词，但不能承诺视频已经去水印或高清化。只有用户明确要求、工具已可用且实际结果可取得时，才推进文件执行与交付。
